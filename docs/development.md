# Development

## Tooling-only bootstrap

This snapshot pins the workspace tools and review conventions. It intentionally
contains no app or package implementation. Do not report a build or test suite
as passing when neither exists yet.

`mise.toml` pins Node **26.4.0** and pnpm **11.9.0**. The workspace catalog pins
shared development dependencies exactly:

| Tool                           | Version         |
| ------------------------------ | --------------- |
| ESLint / @eslint/js            | 10.4.1 / 10.0.1 |
| typescript-eslint / TypeScript | 8.60.0 / 6.0.3  |
| Prettier                       | 3.8.3           |
| eslint-config-prettier         | 10.1.8          |
| globals                        | 17.6.0          |

The base ESLint configuration covers JavaScript and TypeScript without importing
any future app configuration. Svelte-specific tooling will be introduced with
the web workspace, not assumed to exist in this snapshot.

## Commands

```sh
pnpm install --frozen-lockfile
pnpm lint
```

`pnpm lint` checks formatting and ESLint against files that exist. `pnpm format`
writes Prettier formatting. Generated output, operator config/secrets, local
planning notes, and prototype archives are excluded from formatting. The lockfile
is generated by pnpm rather than reformatted by Prettier.

There are no placeholder build/check/test/verify commands. Real web, shared-config,
and CLI code will each introduce their corresponding checks. Browser tests, CI,
and publishing are not part of this commit.

## Review workflow

Complete agent code review before handing changes to the owner. On an explicit
request for staged review, stage one coherent commit and wait for the owner's
manual review before preparing the next. Permission to stage is not permission
to commit or push.

For this tooling snapshot, useful manual verification is a frozen installation
and `pnpm lint` in a directory containing only the staged files. The full local
worktree may already contain later, unstaged work; do not confuse checks of that
combined state with checks of this commit alone.
