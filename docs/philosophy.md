# Philosophy

do one thing. only.
do it well. maybe.

this is a highly opinionated app prioritizing the following principles

1. simplicity (user experience and developer experience)
2. performance (fast enough, but not the fastest)
3. low maintenance (this is just 1, but repeated in new words)

## the one thing

Directory is a sitemap for the apps you use at home. A browser start page for you,
your household, or whoever keeps asking where the photos went.

## a text file

Configuration lives in a text file. Edit it, back it up, reverse it and put it
in git.

## no user management

Everyone sees the same page. Shared sign-in and SSO can control who gets in.

Keep. It. Simple.

## not enough?

you've got options. more features come with more things to configure and maintain.
decide how much you want to take on.

- [dashy](https://dashy.to/) — widgets, themes, and service status checks
- [homepage](https://gethomepage.dev/) — service integrations and widgets
- your own page — hand code it, vibe code it, hard code and maintain it all
